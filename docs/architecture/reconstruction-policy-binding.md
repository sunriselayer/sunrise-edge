# Immutable reconstruction configuration binding

Original signed genesis, an independently supplied ordered policy and a local
logical domain must agree before private reconstruction or control collection.
One private reconstruction owner defines that immutable configuration relation.
It is not fresh serving permission, a complete business cut or destination
activation. [DR-0185](decisions/0185-one-reconstruction-policy-binding.md)
records this boundary; implementation acceptance belongs in [TODO](../../TODO.md).

## Two stages, one defining invariant

The private binding module checks these common inputs without storage I/O:

1. The root has the signed causal profile; policy context, original genesis
   digest, logical domain, original committee and **complete resolver schedule**
   equal that exact immutable root.
2. The policy anchor equals the canonical anchor independently derived from
   that root, including its signed minimum Freeze height.

Use small private typed validation functions, not a public trusted flag,
unconsumed evidence token or universal reconstruction environment. Both actual
consumers invoke the same defining checks and delete their duplicate predicate
and anchor derivation. Current authority, persistence and successful completion
remain with their existing owners.

The stages remain separate because their consumers have different validation
order and diagnostics. The overlay checks its independent history, ordered-leg,
paid-policy and manifest fee-context companions between configuration matching
and anchor verification. Control collection has its own diagnostics and then
constructs its real ordered-history verifier. A policy/history pair with copied
digest/domain/committee bytes still cannot substitute an unsigned historical
anchor for the root's signed Freeze policy.

## Keep the other evidence owners

| Owner | Shared relation | Separate deciding evidence |
| --- | --- | --- |
| Private business overlay | Exact root/policy/domain and independently derived anchor | History identity, execution-policy companions, strict private bootstrap installation and complete original replay |
| Control collection | The same immutable relation and anchor | Authenticated ordered catalogue, actual retained control proofs and complete source observations |
| Saved-cut verification | Uses those existing reconstruction consumers | Untrusted saved-claim bindings, component integrity, independent execution and full package comparison |
| Destination completeness | No replacement by this immutable relation | Fresh lifecycle/progress, exact installed inventory/body closure, own fence and local snapshot continuity |

No incoming epoch, Seal, readiness certificate or stored namespace tag constructs
this binding. Conversely, agreement among the immutable inputs proves none of
those later capabilities. Preserve original receipt-first reconciliation and
all genuine completed-control, saved-cut, import/restart/fencing verifiers.

## Acceptance

Retain historical-policy substitution, signed-Freeze and same-anchor but
different-full-schedule negatives. Exercise both actual overlay and public
control entrypoints, pin combined history/anchor-defect precedence and the
existing exact diagnostics, then run complete required acceptance and fresh
independent exact-head review. No wire type, key family or backend prerequisite
is added.
